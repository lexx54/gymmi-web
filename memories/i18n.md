# i18n Module

## What it does

Adds English and Spanish UI localization for Gymmi web with `i18next` and `react-i18next`.

## Main flows

- `src/i18n/index.ts` initializes i18next before React renders from `src/main.tsx`.
- Language defaults from the browser locale (`es*` => Spanish, otherwise English).
- A stored preference in `localStorage` under `gymmi.language` overrides browser locale.
- `setAppLanguage('en' | 'es')` updates i18next and persists the choice.
- Settings exposes the language picker through `src/components/settings/LanguageSettingsCard.tsx`.

## Key files

- `src/i18n/index.ts`
- `src/i18n/locales/en.json`
- `src/i18n/locales/es.json`
- `src/components/settings/LanguageSettingsCard.tsx`

## Constraints

- The active language is also sent to the API as `Accept-Language` via the axios client (`src/services/api/client.ts`), so backend response messages come back localized (`en`/`es`). See `gymmi-api/memories/i18n.md`.
- Locale files are app-local JSON resources; there is no shared package with the mobile app.
- Brand names, route names, API enum values, and user/API-provided data remain unchanged unless rendered as static mock UI.
- UI strings should use `useTranslation()` and translation keys instead of hardcoded visible English.
